# StackChan illustration references

These game illustrations were generated for taM5CZTyping using the appearance of the M5Stack official StackChan K151 as a reference. They are not official M5Stack application assets or an endorsement.

- M5Stack official K151 product documentation: https://docs.m5stack.com/en/StackChan
- Product reference image: https://m5stack-doc.oss-cn-shenzhen.aliyuncs.com/1205/K151_stack_chan_main_pictures_01.webp
- Stack-chan creator: Shinya Ishikawa (ししかわ) and the Stack-chan community.
- Community project: https://github.com/stack-chan/stack-chan

The application does not include or control StackChan firmware. The mascot is a visual companion inside the CardputerZero game.
