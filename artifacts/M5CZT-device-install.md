# M5CZT USB転送・実機インストール記録

2026-10-24、USB ADBでCardputerZero（aarch64）へ転送し、M5CZT 0.3.1-rev2のインストールを確認しました。

- 保存先: `/home/pi/key-dash_0.3.1-rev2_arm64.deb`（所有者pi）
- Mac/本体のSHA-256一致: `5d1ac8781491c7829d30f90b2c4d63a3e7912fd8502597c08fdb0df5711b2056`
- `dpkg -s key-dash`: `Status: install ok installed`、`Version: 0.3.1-rev2`。
- APPLaunchの表示名M5CZT、実行ファイル、スタックチャン画像の配置を確認。
- `ldd`で全共有ライブラリ解決、`dpkg --verify key-dash`で不一致報告なし。
- OS全体の更新や追加の依存パッケージ導入は行っていません。

## 修正内容

旧rev1パッケージは新設ディレクトリーのtarエントリーがなく、初回インストールで失敗しました。rev2では全親ディレクトリーを先に格納し、検証スクリプトも順序・権限を検査します。旧rev1は履歴資料としてのみ保存し、実機へのインストールにはrev2を使用してください。
