# 配布物・検証資料の保管

このフォルダーには、このチャットで作成した配布物、ソースのスナップショット、操作ガイド、検証画像、デザイン検討資料を保存しています。

最新版の案内: [M5CZT-guide.md](M5CZT-guide.md)。旧名称や旧バージョンの資料は履歴として保管しています。展開済みのMac .appは対応するプレビューZIPに含まれます。

`ARCHIVE-SHA256SUMS.txt` は保存した各ファイルのSHA-256です。ソースZIPは作成時点のスナップショットで、最新のソースはリポジトリ本体を参照してください。

認証情報、実ユーザーのプレイヤーキー・メールアドレス、データベース内容、作業用キャッシュやビルド依存物は含めません。実機動作・Store投稿の状況は各資料の記載時点のものです。
