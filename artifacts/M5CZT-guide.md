# M5 Cardputer Zero Typing (M5CZT) 0.3.1

CardputerZero向けの、小さなキーボードで遊ぶタイピングゲームです。M5Stack公式StackChan K151を参考にした独自イラストと、任意の連絡先登録を追加しました。

- ランキング: https://yuk1-kondo.github.io/key-dash-ranking/
- サイト/APIソース: https://github.com/yuk1-kondo/key-dash-ranking （公開）
- アプリソース: https://github.com/yuk1-kondo/key-dash （非公開、所有者用）

## インストール

実機へ `key-dash_0.3.1-rev2_arm64.deb` をコピーし、`sudo apt install ./key-dash_0.3.1-rev2_arm64.deb`。APPLaunchにM5CZTが追加されます。実機実行はまだ未検証です。

Macでは `M5CZT-macOS-preview.zip` を展開し、M5CZT.appを開いてシミュレーターを試せます。Apple Silicon向けのローカルプレビューで、公証済みの一般向けMacアプリではありません。

## オンライン参加

1. Wi-Fiに接続し、アプリのメニューで **5 Online**。
2. **Enter** → 3〜12文字のプレイヤー名を入力 → **Enter** で登録。英数字・_・-が使えます。GitHubへのログインは必要ありません。
3. **1**=30秒、**2**=60秒、**Tab**=English/Codeを選び、**Enter**でオンラインチャレンジを開始します。
4. 最初の文字を打つと計時開始。単語を打ったら **Space/Enter** で確定、**Backspace** で修正。少なくとも1単語の確定が必要です。
5. 制限時間後、自動で送信します。**4**でランキング、失敗した場合は結果画面の **5**で再送します。

名前・ベストスコア・正確率・記録日は公開されます。30秒/60秒×English/Codeの4部門で競います。アプリは上位5人、Webは上位100人の個人ベストを表示します。

プレイヤーキーは端末の設定フォルダーの `online-player.json` に保存します。ほかの端末へ移るときは非公開でバックアップしてください。キーを他人に送ったり、GitHubのIssueへ貼り付けたりしないでください。パスワード復旧機能はありません。

## 任意のメール登録・変更・削除

1. プレイヤー登録後、**5 Online → 6 Contact** を選びます。
2. 表示されたQRをスマホで読み取ります。コードは10分で失効し、一度の保存または削除に使えます。QRを読めない場合はWebの「連絡先（任意）」からコードを入力します。
3. プレイヤー名を確認し、メールを入力して利用目的への同意にチェックを入れ、保存します。
4. 変更・削除はアプリで新しいQRを発行して同じ画面から行えます。削除してもスコアは残ります。

メールはCloudflare D1に非公開で保存し、公開ランキングやGitHubリポジトリには含めません。未登録でも全ランキングに参加できます。メールアドレスの所有確認と自動送信は実装していません。大会結果の連絡は管理者が行います。管理者用の参照手順はリポジトリの `online/README.md` にあります。

## オフライン

ホームの **1/2/3** は従来どおりローカルプレイです。3は時間制限なしの10単語練習。Tabで単語、0でテーマ、4でヘルプ、Escで戻る/終了。オフラインプレイの記録はネットへ送信しません。
