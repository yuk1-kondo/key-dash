# KEY DASH 0.2.0 検証記録

公開先: https://yuk1-kondo.github.io/key-dash-ranking/  
保存API: https://key-dash-ranking.yukilab-m.workers.dev

## 実装・通信

- C++モデル/controller: 2件成功。既存の修正履歴、WPM不変性、期限、保存、キールーティングを維持。
- Worker/SQLite: 8件成功。公開登録、キーによる本人区別、スコア再計算、4部門分離、個人ベスト、期限、サイズ制限、レート制限、名前重複、CORS、再送、辞書一致を検証。
- 実Wrangler/D1ローカルへ、ネイティブから名前登録→サーバーシード取得→30秒プレイ→打ち間違い修正→送信→D1保存→アプリ内ランキングで同じスコアを取得。最終例18 WPM・97%。
- 公開Workerのhealth/leaderboard、GitHub Pagesの読取り、Macプレビューから公開APIのランキング取得を確認。
- CardputerZero向けAArch64ビルドとMacビルド成功。DebianのELF・実行権限・APPLaunch・アイコン・スクリーンショット・権限宣言・サービス不在を検査。networkのみtrue。
- Mac ZIPはad-hoc署名とstrict検証済み。バージョン0.2.0。ソースZIPに認証キャッシュ・プレイヤーキー・node_modulesを含まないことを確認。

時間/単語部門の切替、更新、公開APIの空状態、参加手順への移動を確認しました。検証中だけ変更したブラウザーの表示サイズとキャッシュ設定は元へ戻しました。

## 残る確認
